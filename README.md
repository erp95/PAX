# PAX 3 Steuerzentrale

Inoffizielle Bluetooth-Steuerung für den PAX 3: Temperatur gradgenau (182–215 °C), Heizmodi, Geschmacks-Profil, Temperatur-Treppe, Licht, Vibration und Sitzungs-Statistik.

**Öffnen:** https://erp95.github.io/PAX/

- **iPhone:** nur in der App *Bluefy – Web BLE Browser* (Safari kann kein Bluetooth).
- **Linux-PC:** in Chrome oder Chromium.

Seriennummer (8 Zeichen, Gehäuserückseite) eingeben, PAX schütteln bis die Blätter blau leuchten, dann „Verbinden“. Die Seriennummer bleibt nur im jeweiligen Browser gespeichert.

Keine Firmware-Funktionen. Protokoll basiert auf dem Open-Source-Projekt pax-romana (MIT).
